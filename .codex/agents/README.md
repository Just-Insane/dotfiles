# Codex role agents

These are user-level reusable role definitions installed from the independent
AI engineering control-plane package. They pin delegated roles to Terra or
Luna; they do not set a global default model or opt unrelated repositories into
hierarchical routing.

The canonical source currently lives at
`personal-systems/tools/ai-engineering-control-plane/agents`. Keep this copy
byte-for-byte synchronized through that package's installer.
